# 矿产资源观察站

新版首页围绕全球报道覆盖、真实现货报价和矿种观察组织内容，采用深蓝、铜色和纸金色设计。主题与中英文切换作用于全站。

## 数据与展示

- 首页通过服务端读取真实 API，成功响应按 300 秒刷新。镜像构建期间后端不可用时，不缓存空首页。
- 四项统计分别为已发布文章、已报道矿种、报道覆盖地区、信源目录数量。信源目录数量不代表已成功采集的数量。
- 地图节点来自 `/api/facets` 的已发布地区标签，使用地区中心展示覆盖情况。连线表示与 MiningIntel 的情报连接，不表示实体贸易路线或矿山位置。
- 价格观察使用 `/api/minerals/锂/prices`，显示报价日期、币种、单位和原文链接。同一产品、来源与报价口径组成一条曲线，横轴保留实际报价日期间隔。
- 48 小时热点为空时，展示真实资料库的高质量精选文章，并明确标为档案精选。
- 元素卡片、地图标记、新闻卡片与 AI 问题入口均可跳转；咨询问题在登录后继续保留，提交仍由用户主动触发。

## 视觉动态

地图支持扫描光带、轨道光点、情报流线和节点波纹；资讯滚动条展示真实文章；价格曲线在入场时绘制；卡片随滚动出现，并提供跟随鼠标的铜色光泽。

地图下方可暂停或恢复所有首页动画，选择会保存在本地。系统开启“减少动态效果”时停用循环动画与滚动条，并保持报价曲线和所有内容可读。

2026-10-22 视觉升级加入地质层理与矿脉光流、地球轨道刻度、蓝金色金属界面，以及矿产行情、全球动向、研究前沿、矿眸智探四个快捷入口。栏目标题与卡片沿用统一视觉层级，阅读进度条与返回顶部基于实际滚动位置。新增效果使用现有 CSS/SVG 和单个被动滚动监听，不增加数据轮询或图形依赖；与全站暂停、系统减少动态、后台标签页暂停共同生效。地质线条是装饰，不代表实测矿藏。

世界地图采用 [Natural Earth 的公共领域数据](https://www.naturalearthdata.com/about/terms-of-use/)，原始数据链接保存在 `frontend/lib/world-land.ts`。使用等距圆柱投影，简化误差小于 0.65 个 SVG 坐标单位。

## 验证与部署

### 全站研究工作台（2026-10-22）

全站加入栏目面包屑、相关入口与快捷导航。顶部搜索按钮或 `Ctrl / ⌘ K` 可打开工作台，输入栏目名称后用方向键和回车跳转；输入研究关键词可进入真实资料检索。手机通过“更多”菜单访问相同工具。

“阅读设置”支持标准/大字、舒展/紧凑排版、深浅主题与动态控制，字号和密度保存在当前浏览器，并在页面首屏恢复。卡片摘要可展开，选中的筛选项可以逐个移除；政策和检索页面提供清除筛选入口。简报可复制或导出 Markdown，保留所选周期、原始摘要与来源，不增加生成内容。

新增样式在 `frontend/app/studio.css`，沿用各栏目原有场景色；长文、对话、证据卡片、表格、空状态和移动弹窗使用一致的阅读层次。快捷工具不增加 API 轮询，所有业务数据继续来自现有接口。

验证覆盖快捷键与焦点返回、字号和排版持久化、筛选 URL、简报真实下载，以及 320/390/768/1440 像素下的栏目和文章/事件详情。先通过类型检查、测试和生产构建，再更新腾讯云前端容器并验证公网效果。

运行 `npm run typecheck`、`npm test` 和 `npm run build` 验证前端。浏览器验证包括真实文章 ID、报价和统计、360–1440 像素布局、手机冷启动、主题切换、搜索 URL 恢复、文章详情、实际动画变化及暂停状态保存。

生产站点位于腾讯云 `http://150.158.163.119:3030`，继续使用 small 部署模式。本次修改仅涉及前端展示，数据库、采集和问答逻辑保持兼容。阿里云 `http://8.156.66.169:3030` 已改为 homePage，8080 商务监测站独立保留。
