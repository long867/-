# 矿眸智探：连续交流与业务场景分析

回答继续区分资料事实、条件性分析、行业知识与行动建议；关键事实沿用句子级原文引用、数值与计量单位校验。没有资料支持的行情、事件、政策和精确预测不会作为确定事实输出。

本轮新增：

- **会话记忆**：按当前登录用户的会话保存关注矿种、地区、产品、业务角色、表达偏好，以及明确提供的库存、交期等场景。最近五轮用于语气与追问，结构化背景独立保留；较旧会话首次使用时从最近五十条用户问题初始化，不从模型回答抽取事实。
- **场景修正**：切换矿种时清除原矿种的库存和产品条件，库存、预算等补充会替换旧条件。最新报价的问题不自动沿用此前年份；概念解释不混入旧新闻。
- **必要澄清**：完全没有矿种的价格查询、含糊的锂产品报价等先询问一个关键条件；已经明确提供的产品不重复询问。简单澄清无需 LLM 调用。
- **自然表达**：先回应本轮关注点，结合采购、项目、供应链等角色解释影响和行动条件；支持简洁或详细表达偏好。
- **继续追问**：回答后提供相关追问按钮；点击将问题放入输入框，由用户决定提交。
- **可见与可清除**：问答页可展开“已了解”的背景。清除当前记忆保留聊天记录，但后续提示不再加载清除之前的历史。

接口 `GET /api/chat/session/{id}/context` 和 `DELETE /api/chat/session/{id}/context` 均校验会话所有权，清除操作与问答共用会话事务锁。其他用户访问返回相同的 404。

公开每日报价已经进入文章证据库，问答可以使用对应知识。国内参考价与其他产地、产品品级不自动互换；报价日期与采集日期分别展示。
