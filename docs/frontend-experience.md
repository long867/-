# 全站动态体验

沿用现有深蓝、铜金主题和真实 API。新增动效只影响呈现，不生成价格、坐标、报价时间或资讯记录。

- `SiteExperience` 在根布局覆盖公共页面、详情页与账号页面：地质等高线、轻量光晕、真实请求进度、卡片滚动入场和桌面悬停反馈。
- `SceneGlyph` 根据栏目提供晶体、全球网络、政策文档、信号轨迹、研究节点与搜索雷达等装饰性 SVG。图形不表示真实行情或项目位置。
- 趋势迷你图、价格折线和简报柱状图仍使用原 API 的真实观测值，仅增加绘制过渡；不生成虚构的中间报价或随机计数。
- `PageMotionProvider` 统一管理导航栏与图谱内的动效控制。暂停选择保存至 `mi-motion`，其他标签页同步；系统减少动态效果优先，切到后台时暂停视觉效果。JS 不可用时正文仍可见。
- 卡片只在首次进入视口时执行短暂动画，不靠隐藏正文等待脚本。滚动观察、鼠标反馈和媒体监听在路由切换时清理，不创建持续的全站 JS 绘制循环。
- 移动端减少粒子与背景层，保留清晰的文字、筛选、错误提示和原有底部导航；支持亮色模式。

验证：TypeScript、既有前端测试、Next.js 生产构建；浏览器检查 20 个路由的桌面、390px 和 320px 布局，以及暂停/恢复、刷新后的偏好保留、系统减少动效和亮色模式。离线的本地检查覆盖加载、错误与登录状态；真实数据与公网发布另行核验，不以模拟数据冒充线上结果。
