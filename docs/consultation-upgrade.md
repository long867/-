# 矿眸智探：对话与分析升级

本次改进在现有模型网关和 RAG 上完成，无需申请新的 API Key，也不在小服务器加载额外模型。

- 对话目标：分别理解直接回答、原因解释、方案比较、行动建议、条件推演和汇报压缩。
- 追问：保留最近的矿种、公司和项目话题，跳过中间的概念解释；比较问题保留比较对象。
- 用户记忆：库存、日耗、交期可以与提问一起输入；更正库存后沿用新条件。可查看或清除会话记忆。
- 可核对计算：只根据明确的同类库存和日耗计算覆盖天数，支持吨与公斤换算。结果属于客户场景，不作为市场统计。
- 自然表达：去掉每段固定的“分析判断/一般行业分析”前缀，用正常段落回答；前端继续说明回答类型并展示引用卡片。
- 回答修正：数字、来源或内容校验失败时最多修正一次；用户问分析却只生成资料事实时补充分析。网关出错时保留已有的有效回答。
- 检索：保留外文公司、项目名，降低“分析、影响、帮我”等指令用词的干扰；关键词覆盖参与候选排序。

验证场景包含“哪个更值得关注”“如果许可放松了呢”“下一步怎么做”“帮我写成汇报”、客户库存更正、单位换算、错误数字修正及修正时模型不可用。现行报价、政策和项目进展仍必须有资料依据；未来影响采用条件分析，不生成无依据的确定涨跌或概率。

模型质量和已入库资料的覆盖仍会影响答案。这里的数字与引用校验能发现部分错误，不代表已自动证明每句话的语义正确。
