# 矿种目录与公开每日行情

`/minerals` 展示 100 项资源目录，按贵金属、有色与黑色金属、新能源与稀有金属、稀土、能源矿产、非金属与化工矿产分组。可搜索中文名称、英文名称、元素符号和报价产品，可筛选仅显示有报价的矿种；筛选保存在 URL 中。

首页展示当前已取得报价的矿种。矿种详情保留来源、币种、单位、产品、价格类型，允许切换不同价格序列。未接入可靠公开报价的矿种保留情报入口，显示“暂无公开报价”，不填入估算值。

## 数据与口径

- 生意社公开现期表：只读取现货列，排除期货结算价和现期差。黄金为元/克、白银为元/千克、铁矿石保留湿吨口径，其余按原表说明读取。
- SunSirs 公开日表：按商品 ID 获取完全标注日期的报价，逐产品与生意社中文基准页交叉核对价格、月日和明确物理单位。标题不明确标注的品级不擅自补全。
- 基准/参考价与实际成交价、金属与原矿、现货与期货分别展示。涨跌幅只对比相同来源、单位、币种的前一观测；首次采集没有历史时显示“暂无对比”。
- `price_records.date` 是原始报价日期；`fetched_at` 是入库采集时间。历史数据原先未知的采集时间保持为空，不回填为今天。
- 每个产品与日期都有稳定的证据快照标识。价格 upsert 使用原有唯一约束，重复执行更新观测、重新核算同序列涨跌幅，不产生重复价格。

## 刷新与运维

Celery Beat 每天北京时间 **08:30、17:30、20:30** 调用 `miningintel.refresh_daily_prices`；只调度已启用的公开报价适配器，保留源冷却时间、分布式锁和最多三次指数退避重试。普通新闻采集任务仍独立运行。

报价会在来源发布之后取得；休市、节假日或供应商没有新报价时保留最近真实日期。页面每五分钟检查数据，服务端目录缓存五分钟，价格提交后清除缓存版本。超过七天的报价标记需要核对。

接口：

- `GET /api/minerals/market`：资源目录、各产品最新报价、覆盖数量和最近采集时间。
- `GET /api/minerals/{name}/prices`：可比价格历史；仍支持日期、来源、价格类型过滤。
- `GET /api/minerals`：兼容原有矿种情报统计接口。

公开报价读取遵守源站 robots，不使用收费数据源密钥。没有启用 LME、Fastmarkets、Argus、SMM 等需要授权的配置。
