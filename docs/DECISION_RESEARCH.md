# 政策、趋势、简报与智能研判

政策列表显示已公开文章对应的政策记录。原文件公布日、资料页发布日期和法规生效日分开标注；战略规划、法规文件与立法进展分别展示。初始影响评分为待评估，不把文章权威性当作法律影响。

趋势页的报道关注度按当前窗口报道量归一化。统计异常热点仍要求充分历史样本、超过历史均值两个标准差且至少三篇报道。价格分析仅比较同产品、来源、币种、单位和价格类型；样本不足时保留判断。`GET /api/trends/overview` 提供日期明确的中文解读。

简报默认使用 `scope=latest`，查询最新有公开资料的实际日、周或月，保留原始周期日期。`current` 和 `previous` 仍可选择；当天没有资料时如实显示空。资料撤回后重新计算公开统计，丢弃旧报告中的事件和政策证据。

`/research` 可以按矿种、地区和经营角色查看研判。公开概览即时呈现资料摘录、条件性影响及核实建议；登录后可用已配置的模型生成与主题相关的研判并保存个人历史。接口如下：

- `GET /api/research/overview?mineral=锂&days=30`
- `POST /api/research`：`{mineral?, region?, days, role, focus}`
- `GET /api/research/history`
- `GET /api/research/reports/{id}`

已知事实必须有逐字原文引用并通过数字、单位检查。可能影响必须说明成立条件，不输出价格目标、概率或保证结论。生成失败时保留基于真实资料的分析和行动清单，明确标注模式。历史报告检查账号归属、公开状态与原文哈希；资料撤回或修改后需重新生成。数据库迁移为 `0007_research_reports`。

研判用于经营准备、资料核实、政策适用检查和项目跟踪。资料支持程度与发生概率分开表述，连续价格不足、历史政策和资料时间滞后均在页面标注。
