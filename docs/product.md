# MiningIntel 产品定义 · v0.1

## 定位与价值

面向矿产研究、产业经营与政策分析，把全球分散资讯转化为可筛选、可追溯、可咨询的情报。核心价值是缩短“找到信息 → 判断信息可信度 → 理解事件变化 → 查证结论”的时间，而非仅罗列新闻标题。

借鉴 [AIHOT 的报道汇聚与摘要组织](https://aihot.news/about) 和用户指定的热点时间线、卡片流、标签体验；MiningIntel 增加矿种、国家、公司、项目与政策实体，展示质量、单位、语种和引文。对标页面直接访问未成功，定义主要依据用户提供的体验要求及该产品可检索的公开说明。

## 目标用户与关键任务

- 研究员：检索特定矿种/国家，查看原始材料、事件中的多篇报道，导出可核查的研究依据。
- 矿业与供应链团队：跟踪许可、出口限制、产能与项目进度，关注统一口径的价格异动。
- 政策分析人员：区分发布日期、生效日期、法规适用范围，比较政策的关联报道。
- 内容运营：管理信源权威度与频率，审核加工结果，纠正标签，查看失败任务并重试。
- 第三方开发者：用版本化 REST API 读取文章、事件、价格和政策；认证后调用问答和订阅。

## 信息架构

“情报中心”包含资讯流、事件时间线、价格、全球地图、政策和简报。资讯卡片优先显示中文标题/摘要、来源、时间、语种、矿种/地区/主题和质量分；原文与译文可展开对照，出处可直接打开。

“AI 咨询”包含新建咨询、历史会话、问题输入、逐条引用、原文片段与字符位置。来源不足显示证据不足；LLM 不可用时以证据摘录回答。历史问题参与多轮检索，已生成答案不当作新的可信文献。

“我的订阅”维护矿种、地区和频率偏好，生成站内关注流。“管理后台”维护信源、启停、采集触发、文章审核、标签编辑和任务记录。

## 交付能力

1. RSS/Atom、静态网页、Playwright 动态正文页、字段可配置的 JSON API；支持 ETag、Last-Modified、URL 去重和请求体积限制。
2. trafilatura 清洗、双语矿业词典 + spaCy EntityRuler；LLM 可配置翻译、摘要、开放实体与标签。译文成功才标记已翻译。
3. PostgreSQL 数组筛选与事件聚类。启用 BGE 后使用语义相似度，关闭时仅合并同标题事件。
4. 过去 24 小时的矿种提及热度、与此前 24 小时对比、统一序列价格变化、带链接的每日/每周简报。
5. LlamaIndex 原文分块、双语关键词与 pgvector/Qdrant 召回、RRF、BGE 重排、逐句引用校验、最近 5 轮历史与用户隔离的会话。
6. Next.js 页面、TanStack Query 缓存、shadcn 风格基础按钮、Recharts、Leaflet 国家级资讯覆盖。
7. 管理 API、JWT 权限、任务日志、开放 API 文档、Compose 与 GitHub Actions。

## 明确的初始边界

动态采集器针对单篇正文页面；站点列表翻页、登录付费页面、验证码、交易所授权行情和特定 PDF 研报需新增来源适配器。多语言采集与 BGE 支持广泛语言，初始规则词典主要覆盖中文/英文；其他语言依赖模型，不承诺训练过的行业 NER 精度。

地图显示国家层级资讯覆盖，尚未维护矿区坐标/储量 GIS；价格按来源、矿种、币种、单位区分，未做汇率换算与跨来源指数合成。订阅提供站内流和频率偏好；邮件/短信推送尚未接入。开放 API 未实现商业 API Key、租户计费与配额。

全量语料指已入库并发布的文本，不包括未采集内容、付费全文、待审核材料或实时互联网。价格 API 快照可被问答引用；管理员单条手工价格写入用于结构化行情。政策影响分初始为未评估的 0；后续人工/规则模型评分须记录评分依据。质量评分与相关度是透明启发式，不等于真实性证明。

## 产品规则

- 保留原文、原文 URL、采集时间和可得的发布时间。未知发布时间/生效日存 null，不虚构时间。
- 同事件允许多个信源；展示来源数量与追溯链，不把转载数量直接视为独立验证。
- 默认人工审核发布。高质量自动发布需主动启用，并持续抽检政策、数字和单位。
- 热度按文章采集时间统计，是平台覆盖内的资讯热度；新增热点没有历史基数时用“新出现”，不输出无穷增长率。
- 答案逐论点引用。引文必须来自召回材料中的连续原文；模型推断与事实支持程度仍需评估。
- 内容版权保留原信源；后台接入前确认公开抓取和使用条件。

## 验收与后续计划

初始工程验收：重复采集不产生重复 URL；未发布材料不可公开检索；问答引用可按字符位置还原；普通用户不可审核或读取他人会话；迁移可降级再升级；前端类型检查和生产构建通过。

试运营目标需以实际标注集验证，以下为目标而非已测结果：重点源新内容 P95 入库延迟 ≤ 两个采集周期；来源/片段定位正确率 100%；100 个人工标注矿业问题的 Recall@20 ≥ 90%、答案有充分证据支持比例 ≥ 95%；按语言/来源统计采集成功率，政策日期和价格单位单独抽检。

第一阶段：接入优先国家政府/监管、矿业公司公告、授权价格与行业媒体；建立 100–300 个咨询评测问题和人工事件标注，记录模型版本、成本、延迟。

第二阶段：政策影响评估、事件演进综述、查询改写与时间意图、PDF/OCR、更多语言词典、官方企业别名和项目知识图谱、邮件报告与 Webhook。

检索工程已补齐增量索引、全量重建、Qdrant 镜像与撤回状态校验，详见阶段 2 使用说明。后续扩容：独立推理服务、分区/读副本、API Key/配额/商业租户、精确 GIS、来源纠错和跨转载撤稿传播。启用 Qdrant 服务端后按真实语料测量容量、延迟和召回质量。
